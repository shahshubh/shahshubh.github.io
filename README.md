# shahshubh.github.io

## Updating work experience

Edit `public/work_experience.json`. Each entry supports:

- `role`, `company`, and `time`
- `description` as an array of bullet points
- `skills` as an array
- `icon`: `work`, `github`, `react`, or `education`
- `iconBackgroundColor`, `iconColor`, and `borderTopColor`
- optional `link`

Keep the entries in newest-to-oldest order. Commit the JSON change and deploy the site to apply it.
